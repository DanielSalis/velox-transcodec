Instale no Linux.

Ver requisitos

Fedora

RPM ou build local

Build local disponível

Na raiz do repositório, instale o binário da prévia 0.1.0 em ~/.local/bin com o Cargo. O RPM está em preparação.

cargo install --path . --locked --root ~/.local

Flatpak

Bundle local

Em preparação

Comando previsto para instalar o bundle na sua conta quando o arquivo estiver disponível.

flatpak install --user ./velox-transcode.flatpak

Arch Linux

Tarball para x86_64

Em preparação

Comando previsto para instalar o tarball em ~/.local. O binário depende de Qt 6 e do FFmpeg.

mkdir -p ~/.local && tar -xzf velox-transcode-linux-x86_64.tar.gz -C ~/.local

Perguntas frequentes.

Ver instalação
O que preciso no Fedora?
Para compilar, use Rust 1.95 ou mais recente e Qt 6. Para converter, instale FFmpeg e ffprobe com suporte a H.264.
Preciso de uma GPU?
O Velox testa VA-API e NVENC no host. Com libx264 disponível, você pode converter pela CPU.
Quais formatos posso abrir?
Você pode abrir MP4, MKV, WebM e MOV, conforme os decoders incluídos no seu FFmpeg.
Posso manter o áudio original?
Use Copy se o container aceitar o codec. Se houver incompatibilidade, selecione AAC a 192 ou 320 kbps.
O que acontece se eu cancelar?
A fila remove os temporários da conversão interrompida e conserva os arquivos já publicados.
Meus arquivos saem da máquina?
A aplicação trabalha localmente. A demo do navegador usa arquivos de exemplo e simula o processamento.
